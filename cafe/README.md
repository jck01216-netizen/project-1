# 구선생커피 홍보페이지

외부 공개 전 검토를 위한 로컬 정적 사이트입니다. 서버·설치·외부 라이브러리 없이 `index.html`을 브라우저로 열 수 있습니다. Node.js가 없는 실행 환경에 맞춰 React/Vite 대신 표준 HTML/CSS/JavaScript로 구현했습니다.

## 수정 방법

- `content.js`: 매장 정보, 대표 문구, 메뉴·가격·이미지, 카카오톡 설정
- `styles.css`: 디자인과 반응형 스타일
- `assets/`: 로고 심벌과 생성 연출 이미지. 실제 사진으로 교체한 뒤 content.js의 경로·표시 문구도 수정하세요.
- 페이지의 정적 기본 정보는 JavaScript가 꺼져도 제공됩니다. 운영 정보를 바꿀 때 `index.html`의 기본 정보·검색 설명도 함께 맞추세요.
- 카카오톡은 채널 URL을 입력하고 `kakaoEnabled: true`로 바꾸면 활성화됩니다. https://pf.kakao.com/ 또는 https://qr.kakao.com/ 주소를 사용하세요.

## 미리보기

Node/Python 없이 PowerShell로 로컬 서버를 띄웁니다(웹폰트·이미지 경로 확인용).

```
powershell -NoProfile -ExecutionPolicy Bypass -File .claude/serve.ps1
```

→ http://localhost:5173

## 구성

- 첫 화면: 클로버 초콜릿을 올린 당근케이크 엽서 이미지, 대표 문구, 매장 찾아오기·단체모임 문의 버튼, 20명·주차 6대 배지, 한국 시간 기준 영업 상태 표시
- 공간: 연출 이미지 3컷(같은 이미지를 다른 구도로 크롭 — 실제 사진 확보 시 `index.html`의 `#space` img src만 교체) + 공간 특징 4개
- 메뉴: 커피·디저트 그룹, HOT·ICE 동일 가격 표시, 추천 조합(세트 아님 명시)
- 모임·대관: 조건 4개, 친구/학부모 모임 장면, 문의 3단계, 전화 버튼, 카카오톡 준비 중
- 오시는 길: 주소 복사, 요일별 영업(오늘 강조), 네이버 지도·카카오맵 주소 검색 링크
- 모바일: 첫 화면을 지나면 하단 전화·길찾기 바가 나타남
- 폰트: Noto Serif KR(제목), Pretendard(본문) — 모두 OFL, 오프라인 시 시스템 폰트로 대체

## 공개 전 확인

1. 디저트 가격과 음료의 2,801 / 3,301 / 3,801원 최종 확인
2. 지도 검색 결과의 매장 위치·입구, 실제 주차 안내 확인
3. 실제 매장·메뉴 사진 확보 및 연출 사진과 실제 차이 확인
4. 로고·대표 문구 확인
5. 도메인·공개일 확정 후 canonical, 공유 URL·이미지 설정
6. 실제 모바일에서 전화 앱과 지도 연결 확인

가상 모델은 합의한 우선순위에 따라 1차에서 제외했습니다. 대관료·예약금·취소 정책은 만들지 않고 상담으로 안내합니다. 외부 배포는 하지 않습니다.

## 이미지 제작

첫 화면과 공유 카드는 `assets/og-clover-cake.jpg`를 사용합니다. 이미지 속 손글씨가 잘리지 않도록 1200:630 비율로 전체를 표시하며, 모바일에서는 본문 위에 배치합니다. 대표 이미지 경로·대체텍스트·연출 표시는 `content.js`에서 관리합니다. 공간 소개 사진은 기존 공간 연출 이미지를 유지합니다. 이 카드를 사용해도 당근케이크 메뉴가 추가되지는 않습니다.

`assets/greentea.jpg`(녹차라떼)도 Unsplash 무료 라이선스 사진입니다(Alana Harris 촬영, https://unsplash.com/photos/C63YZ33DdvY, 640×640 크롭). `assets/tiramisu.jpg`(티라미수)도 Unsplash 무료 라이선스 사진입니다(Aleksandra Tanasiienko 촬영, https://unsplash.com/photos/xPBUzVMKKTw, 640×640 크롭). 출처 표기는 의무가 아니지만 기록해 둡니다. 실제 매장 사진이 생기면 교체하세요.

나머지는 내장 image_gen으로 제작하는 연출 이미지입니다. 각 최종 프롬프트는 `image-prompts.json`에 기록합니다. 실제 장소 또는 실제 메뉴를 촬영한 사진이 아닙니다.
